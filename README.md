# ddtql-go
Go toolkit for DTQL: parser, AST, validation, linting, formatting, and query execution.

## Used in DataTug development

[DataTug](https://datatug.app) is evolving its query contract around TugQL and TugQT; this Go toolkit is part of the broader implementation ecosystem. [See the tools behind DataTug](https://datatug.app/en/under-the-hood/tools-we-built/#query).
